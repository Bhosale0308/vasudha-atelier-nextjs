# Vasudha Group — Atelier Website

A fresh, editorial-style Next.js website concept for Vasudha Group.

## Requirements
- Node.js 20.9+ recommended
- npm

## Run locally
1. Extract this ZIP.
2. Open the extracted `vasudha-atelier` folder in VS Code.
3. In the VS Code terminal, run:

   ```bash
   npm install
   npm run dev
   ```

4. Visit http://localhost:3000

## Notes
- This is a standalone project and will not overwrite your existing site.
- Architecture photos use remote Unsplash image URLs and require an internet connection.
- Replace the reference images with approved Vasudha Group project photography before production.
- Verify project details, RERA details, and contact information before publishing.
